# 2026-10-30 「いつもの女の子」出会い連動・匿名継続

## 変更
- `/lab/transparent-lounge-shortcuts/`：初めての人には「いつもの女の子」領域と空の点線丸枠・「出会った女の子がここに表示されます♡」だけを表示。美咲アイコンは隠す。
- 同一ブラウザの `misaki-chat-history` に `role:"user"` の発話がある場合、美咲アイコンを表示し、`/chat` へ直接進める。
- `app/chat/anonymous-session-guard.tsx`：Supabase匿名セッションが保存されている限り、ブラウザ再起動時に匿名アカウントを作り直さず、同じ匿名 user.id を維持する。既存の会話履歴・owner照合処理は維持。ユーザーが明示的にログアウトした場合の処理は変更しない。
- ブラウザデータ削除・プライベートモード・Supabaseセッション喪失では匿名アカウントが再作成され、復旧保証はない。別端末での継続にはメール登録が必要。
- アイコン写真は従来の仮素材。ユーザーが提示した正式な丸写真への差し替えは未実施。
- 複数キャラ対応・キャラ別の関係履歴は将来対応。今は美咲のみ。
- 既存チャットのメッセージ構造、DB、RLS、認証API、他のラウンジページは変更なし。

## 実機確認
1. 新規匿名ユーザー：空枠表示→美咲タップ→オープニング→チャットで発話。
2. ラウンジ再訪：美咲のアイコンが表示され、タップで会話再開。
3. Safari完全終了→翌日同一端末で再訪：会話とアイコンが維持。
4. 登録済みユーザーのログイン・ログアウトで他人の会話が混在しない。
5. ブラウザデータ削除時は初期状態に戻る。

## 既知の制約
- 保存されたSupabase匿名セッションが有効であることが前提。端末データ消去後の復旧はできない。
- 会話済み判定は現在ローカルのユーザー発話のみ。サーバーにのみ存在する履歴を自動復元する判定は対象外。
