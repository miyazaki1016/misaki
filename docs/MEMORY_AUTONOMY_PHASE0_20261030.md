対象: 実装設計仕様 v0.1。既存機能の再利用を優先し、段階的に拡張する。

## 開発方針と設計概要

1. 記憶は事実、想い出は経験の意味、感情は現在の反応、関係性は長期の蓄積として扱う。
2. 公式の世界観とユーザーごとの出来事を分け、個人的な記憶や会話を他ユーザーへ共有しない。
3. 同席したキャラでも解釈は異なる。聞いていない話を当然知っている状態にしない。
4. 固定の人格核と、経験で変わる気分・関係性を分ける。5人を同質化させない。
5. 時間経過だけで許しや和解を成立させない。ユーザー参加の約束は留守中に勝手に完了させない。
6. 留守中の日常は必要なときに少量生成する。何も起こらない期間も許す。
7. 想起は会話に合うものだけとし、機微な話題や嫌な経験を繰り返し蒸し返さない。
8. 判断理由は調整に使える形で残し、個人情報の全文を無制限に保存しない。

共通の出来事に対して各キャラが解釈を持ち、その解釈を既存の感情・関係性機能へ渡す。
次の行動と会話は、現在の気分だけでなく、人格・過去の経験・未完了の約束を踏まえて決める。

## 実装順序と確認事項

| 段階 | 作るもの | 主な合格条件 |
|---|---|---|
| 0 | 現状監査・公開資料と詳細資料の分離 | 機能の現在地、未確認、判断理由を区別できる |
| 1 | 出来事・参加者・出典・期限を扱う基盤 | 試験環境で重複・期限・利用範囲を検証し、既存会話を変えない |
| 2 | キャラ別の想い出と想起候補 | 同じ出来事でも視点が異なり、知らない経験を語らない |
| 3 | 既存の感情・関係性への接続 | 減衰・未解決・修復途中・和解を区別できる |
| 4 | 約束・行動候補・結果 | 「何もしない」を含め、本人参加の約束を勝手に完了しない |
| 5 | 留守中の日常 | 長期不在でも生成量が増え続けず、同じ出来事を重複生成しない |
| 6 | 自然な想起と調整 | 会話への適合、反復、人格差、判断理由を評価できる |

実装前に5人の設定状況を確認する。設定不明のキャラを美咲の複製や仮人格で補完しない。
人格が未確定でも進められる共通基盤は、正式キャラと明確に区別した試験データで検証する。

## コストと評価

常時生成を避け、処理期間・生成数・候補数・実行時間に上限を設ける。
ルールで扱える判断は再利用し、自然文生成が必要な場面にモデル利用を絞る。
削減率や重みは先に固定せず、会話品質・生成回数・応答時間を測って決める。
既存の関連テスト82件は前回監査時に成功。新機能・実機品質の合格を示すものではない。
今回は資料の編集のみのため、機能テストの追加実行はしていない。
