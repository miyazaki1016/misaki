# Misaki 記憶・想い出・感情・自律日常：公開用総覧

作成: 2026-10-30。状態: ローカルでの公開準備中。公開・PR作成は未実施。

## 機能概要

会話と日々の出来事をもとに、キャラクターごとの記憶・想い出・感情・関係性を継続させる。
出来事の事実と各キャラの意味づけを分け、5人それぞれの個性を維持する。
公式の世界観とユーザーごとの経験は分離し、私的な会話を他ユーザーへ共有しない。
留守中には小さな日常を生成できるようにするが、本人参加の約束や重大な関係変化を勝手に完了させない。

## 開発状況

会話履歴・長期記憶・感情と関係性・ラウンジには既存機能があり、再利用を優先する。
キャラ別の想い出、約束の継続、留守中の日常、自然な想起と調整機能は段階的に拡張する。
美咲の人格実体は確認済み。他4人の正式な設定資料は実装前の確認事項として残る。
今回の作業は監査と資料整理であり、これらの新機能を実装済みとは扱わない。

## 実装順序

1. 出来事・参加者・出典・期限を扱う基盤
2. キャラ別の想い出と想起候補
3. 既存の感情・関係性機能への接続
4. 約束・行動候補・実行結果
5. 上限付きの留守中の日常生成
6. 自然な想起と判断理由を使った調整

各段階で既存動作と人格差を検証し、処理負荷と会話品質を測定する。
