## V0で保護すべき意味
イベント0件時は「取得範囲で大きなイベントを確認していない」という**取得範囲の限定**を伝える。これを「現実に何も起きていない」という断定に変えてはいけない。また、ニュースを見た/見ていない等の架空の情報入手経路を語らない、未取得の出来事を捏造しない、イベント情報を毎ターン話題にしない、というガードがある。

routeのsystem prompt側にも、天気・交通・羽田・地震・警報について「ニュースで見た」「SNSで見た」等の架空の経路を禁止する独立した規則が存在する。**ただし語彙・適用範囲・回答例は完全一致ではない**。一方の削除で同じ振る舞いが維持されるとは証明されていない。
