# ラウンジ「いつもの女の子」ショートカット配置試作（2026-10-30）

## 目的
ユーザーが提示した丸型の美咲顔アイコンを参考に、既存の縦画面ラウンジを壊さず、画面上部へ直通ショートカットを配置してiPhoneで比較する。

## 実装
- 独立ページ `/lab/transparent-lounge-shortcuts/` を追加。従来の `/lab/transparent-lounge/` と縦型 `/lab/transparent-lounge-vertical/` は変更なし。
- 画面上部に「いつもの女の子」と丸アイコンの横並び領域を配置。既存の24fps透過WebP・背景・21秒オープニングと操作導線はそのまま。
- 現時点ではユーザーの提示画像そのものがリポジトリに未配置のため、公開済みの `/misaki-profile.webp` を仮アイコンとして使用（最終差し替えが必要）。
- 既存のブラウザ保存 `misaki-chat-history` に会話履歴がある場合に限り `/chat` 直通を有効化。履歴がない場合はUIを見せるだけの配置サンプルにしてチャットへは遷移しない。
- 匿名ログインのブラウザセッションを跨ぐ保存・メール登録・複数キャラ対応・チャットへの完全な状態連携は、今回**実装しない**。現時点での会話履歴は美咲単独のため、将来複数キャラにするときはキャラID付きの関係保存を設計する。
- 本試作では画面左からのソファ表示、女の子の選択、右・左スワイプ、オープニング動画の表示とスキップは維持。

## 実機で確認
- 上部ショートカットが顔やタイトルと重ならないか
- 丸アイコンのサイズとラベルが適切か
- 会話済みのときのみ直通が有効か
- ソファの24fps・縦オープニングに影響がないか

## 本採用前の対応
- ユーザー提供の丸型美咲アイコンを正式公開素材として配置
- 匿名履歴の継続方針を決め、キャラ別の会話履歴判定を行う
- ラウンジの上部に最大3人のショートカットを置く場合、折返しまたはスクロールUIを検証

- 画面中央下の名前の左右に小さな「‹」「›」ボタンを配置。48pxタップ領域・アクセシビリティ用の説明あり。
- 既存の左右スワイプと、中央の美咲をタップして21秒オープニングを見る操作は維持。
- 初回だけ「左右にスワイプして女の子を選んでね ♡」を約4.2秒表示。sessionStorage による同一タブでの再表示抑止。操作するとすぐ非表示。
- 「いつもの女の子」欄を少し小型化し、ラウンジの美咲のアニメーションサイズ／ソファ位置は変更しない。
- 既存の縦画面ラウンジおよび旧比較ページは変更なし。このショートカット比較ページのみ更新。

## 2026-10-30 ラウンジから既存チャットへの本接続（PR作業）
- 対象: `/lab/transparent-lounge-shortcuts/` と `/lab/transparent-lounge-vertical/`。
- 初回（ブラウザにユーザー発話履歴がない）: 中央の美咲を選ぶ → 21秒の縦型オープニング → 自動終了またはスキップで `/chat` にページ遷移。
- 同じブラウザにユーザー発話履歴がある: 中央の美咲を選ぶ → オープニングを省略して `/chat` に直接遷移。「いつもの女の子」丸アイコンからの直通は従来どおり。
- ナビゲーションは二重起動防止フラグと `window.location.assign('/chat')` を使用し、動画・ダイアログを停止してから遷移。
- 既存の `/chat` 側の `AnonymousSessionGuard`、会話履歴、保存・関係性、認証・DBは変更なし。匿名ユーザーの継続仕様も従来どおり。画面を開くと既存ガードが匿名認証を行う。
- 元の試験用 `/lab/transparent-lounge/` とMuse v3比較ページは変更しない。
- 実機確認点: 新規の終了/スキップ双方で会話に到着、会話済み直通、既存会話の保持、匿名とメール登録済みの振る舞い、ブラウザ復元、戻る操作。

## 2026-10-30 チャット遷移時のラウンジ一瞬再表示を修正
- iPhone実機で「オープニング終了／スキップ→チャット」切替時に一瞬ラウンジが見える不具合を報告。
- 原因：動画ダイアログを `close()` してから `window.location.assign('/chat')` するため、ページが変わる直前に背面ラウンジが露出していた。
- 修正：遷移フラグを維持し、全画面黒カバーをダイアログのトップレイヤー内に追加（直通時はbodyへ追加）、ダイアログを閉じずにチャットへ移動。2フレーム後に遷移することで黒カバーを描画させる。
- ブラウザの戻る操作でBFCache復元したときの黒カバー除去とダイアログ復旧も追加。
- 既存の21秒MP4、14秒WebP、匿名認証、チャット本体に変更なし。
- iPhoneで①ムービー完走、②スキップ、③会話済み直通、④戻る操作の4パターンを再確認。
