## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
## 変更内容
- `deriveProactiveTags` を感情→行動の順で解決するよう整理
- `PULL` が affectionate / romantic / cheerful などの甘いタグを抑えるよう修正
- `CHASE` は生活根拠がないときに `check_in` を強制しない
- `RECONNECT` は `miss_you/check_in` 固定ではなく、安心・嬉しさ寄りの `soft/cheerful` に調整
- `WAIT` は detached な `calm` より `soft/casual` を優先
- `SULK` は軽い拗ねとして cheerful/playful を抑えつつ calm/casual に調整
- 7日以上空いた場合の `miss_you` は RECONNECT / PULL / SULK では強制しない

## 目的
チャット側の行動ガイドで定義した意味と、自発メッセージ側の派生タグが矛盾しないようにします。

## 非変更範囲
- 行動状態そのものの判定
- direction 判定
- 送信可否・送信間隔
- 写真添付率
- 既存写真ファイル
- チャット・記憶・認証・利用回数

```
