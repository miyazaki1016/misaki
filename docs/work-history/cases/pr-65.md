## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
## Summary
Enable the existing bounded Gemini retry policy for Relationship Analyzer and Critical Validator calls instead of explicitly disabling physical retries.

## Production evidence
Relationship backlog recovery is working after PR #64, but `relationship_analyzer` has returned HTTP 503 repeatedly. Each processing activity currently performs only one physical Analyzer attempt because `transientRetryDelaysMs` and `timeoutRetryDelaysMs` are explicitly empty.

## Change
- transient retry delays: 2s, 5s (existing generator default policy)
- timeout retry delay: 2s (existing generator default policy)
- applies to Relationship Analyzer and Critical Validator

## Non-goals
No change to oldest-first ordering, fail-closed semantics, Evidence/Episode/Pattern rules, relationship scoring, START_AT, or database state. No Production data mutation.
```
