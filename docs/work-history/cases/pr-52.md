Production validation confirmed Relationship Engine v1.1 is processing normally after the polarity schema fix.

This cleanup removes only the temporary diagnostics introduced by PR #49/#50:
- removes exception name/message from the top-level Relationship retry log
- removes Gemini provider status/error detail logging
- removes the diagnostic-only test file

Keeps:
- RELATIONSHIP V1 PROCESSING RETRY REQUIRED operational signal
- polarity type: INTEGER with parseEvidence() enforcing ±1
- ordinary chat behavior
- DB/lease/retry/state contracts
- fail-closed Analyzer/Validator behavior

No environment or DB changes.
