## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
Productionで残った5秒周期GETを推測ではなく実証する仕上げ。

- ConversationHistorySync のGETに `source=conversation-history-sync` を付与
- server response が `ephemeral:true` なら、そのmount中のpermanent history syncを恒久停止
- auth-kindもanonymousへ補正
- regression contract追加

これによりclient側匿名フラグに差異があっても、serverが匿名と確認した時点で追加GETを止める。
```
