## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
## Summary
- Treat an expired anonymous relationship checkpoint as non-importable instead of throwing during permanent processing.
- Keep invalid/unverifiable *live* roots fail-closed.
- Add a regression test proving an expired checkpoint performs no import/model/write and returns cleanly.

## Why
Production investigation found a permanent user's oldest `chat_turn_completed` repeatedly failed before `relationship_analyzer` because an expired `misaki_temporary_roots` row was still present. Oldest-first recovery then kept retrying that poison turn and blocked later turns.

## Scope
No Relationship semantics, ordering, START_AT, Evidence/Episode/Pattern rules, or DB data are changed. No Production rows are manually modified.
```
