## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
初期状態から「すでに恋人」と固定していたため、はじめまして直後でも「ずっと前から大好き」など関係履歴を先取りする返答が出ていました。

変更:
- 固定人格から「最初から恋人」を削除
- 関係性は会話・記憶・relationshipPointsで育てる
- relationshipPointsは親しさの目安で、交際事実そのものではないと明記
- 初期段階では強い愛情表現・過去からの恋愛関係・嫉妬/強い甘えを抑える
- 30/80/160ポイントで距離感は深めるが、恋人関係を名乗るには会話/記憶の根拠を要求
- fallback persona と Body Clock fallback も同じ思想に統一
- active persona DB module も migration で更新

Production DBのactive persona moduleには同じ変更を先行反映済み。
```
