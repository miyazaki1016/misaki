## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
Production smoke test found the first post-cutover permanent turn saved successfully, but Relationship Engine processing failed at the analyzing stage while ordinary Gemini chat returned 200.

This hotfix:
- adds optional Gemini responseSchema support to the shared JSON generator
- applies a strict structured-output schema only to Relationship Analyzer and Critical Validator
- keeps the existing fail-closed parse/validation boundary
- does not change ordinary chat generation behavior
- does not change DB/lease/state mutation contracts

Observed production request remains safely journaled as failed and is eligible for normal retry after deployment.

Do not change Relationship Engine cutover variables.
```
