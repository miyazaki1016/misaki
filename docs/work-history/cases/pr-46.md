Record the production Relationship Engine v1 DB contract in GitHub so application integration is safe across multiple workers and every permanent Relationship mutation is fenced by the active lease token.

The intermediate/import v2 RPCs now contain their canonical write logic directly; they no longer call the legacy v1 mutation RPCs.
