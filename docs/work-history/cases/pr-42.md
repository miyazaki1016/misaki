## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
通常の応答待ち1.8秒で「美咲ちゃん、ちょっと忙しそう…」へ切り替わっていたタイマーを撤去します。通常待機は従来の typing indicator のままにします。

Gemini の 429/502/503/504 に対するサーバー側自動再試行ロジックには触れません。

実際の transient retry 中だけ専用表示をリアルタイムに出すには、現在の単発 HTTP 応答ではサーバー内部の retry 状態をブラウザへ途中通知できないため、別途ステータス通知方式を設計します。まず誤表示を止める最小修正です。
```
