```text
## 変更内容
- `ProactiveDecisionContext` に派生 `tags` を追加
- emotion / action / direction / timeBand / lifeConfidence から表現タグを一意に生成
- Body Clock のメッセージ生成ガイドと写真選定が同じ派生タグを共有
- 写真選定の本文キーワード推定をやめ、decision context を親に統一

## 目的
旧タグロジックと新しい感情・行動エンジンの二重判断をなくし、
`関係状態 → 感情・行動 → direction → 派生タグ → 文面・写真`
の一本の因果に揃えます。

## 非変更範囲
- チャット側の会話・記憶・利用回数・認証ロジック
- Body Clock の送信間隔・送信可否ゲート
- 写真添付率（34%）
- 既存の写真ファイル

```
