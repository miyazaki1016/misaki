## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
Production diagnostics confirmed the poison request fails because Analyzer output contains a supportingTurn that is not an exact substring of the user message.

This change:
- normalizes polarity transport exactly as before
- ignores only evidence candidates whose supportingTurn is not a non-empty <=96-char exact substring of the user message
- keeps all remaining candidates under the existing strict parseEvidence() validation
- preserves DB, lease, retry, state, and critical-event contracts
- prevents Misaki-generated wording from becoming self-reinforcing relationship evidence

A regression test verifies an ungrounded candidate is treated as no evidence rather than poisoning chronological processing.

Temporary diagnostics remain for one production verification pass.
```
