## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
## 変更内容
- `lib/proactive-photo.ts` の本文キーワードからの独立タグ推論を停止
- 旧 `/api/proactive` 側は時刻・関係ポイント・直近写真だけで互換選定
- 公開型と既存写真メタデータは互換性のため維持
- 意味タグの判断元を Body Clock の `ProactiveDecisionContext` に一本化

## 目的
PR #12 で導入した
`関係状態 → 感情・行動 → direction → 派生タグ → 文面・写真`
を唯一の意味判断系にし、旧ルート側の独立タグ推論が将来矛盾を作らないようにします。

## 非変更範囲
- Body Clock の新しい派生タグロジック
- チャット・記憶・認証・利用回数
- 写真添付率 34%
- 写真ファイル
- 既存の公開型・写真メタデータ
- 時間帯・関係ポイントによる旧ルートの写真候補絞り込み

```
