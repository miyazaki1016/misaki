## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
The published approval dashboard included a second `</script></body></html>` and ~4.7 KB of duplicate JavaScript text after the real HTML document, which appeared as raw source in Safari. Remove everything after the first closing HTML document. Strengthen CI assertions to detect an extra closing script tag or leaked text after `</html>`. No app/DB/Push changes.
```
