## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
Production移行の仕上げ。

- 匿名ブラウザは permanent `/api/persona/history` GET 同期へ入らないよう二重ガード
- auth state changeでも匿名sessionから同期を起動しない
- Vercelから403になるJR東日本ページを毎会話fetchしない（公式のserver-consumable sourceが用意できるまでoptional sourceとして停止）
- global metadataの固定「タクドラの彼女」「東京のタクシードライバー向け」を一般化
- 回帰契約を追加

既存の匿名temporary canonical root、恒久history復元、他の生活イベント取得は変更しない。
```
