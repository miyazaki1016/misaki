# 美咲 キャラクターマスター v1（実験用）

状態: **デザイン承認済み／画像ファイルのGitHub格納は未完了**。本番反映禁止。基準は会話でユーザーが提示した**現行LPの美咲の画像**。2026-10-26に制作した最新のマスターシートは補助資料であり、LPと差がある場合はLPを優先する。

## 不変条件
- 名前：美咲（Misaki）。設定年齢：38歳。
- LPの顔の輪郭、目元、鼻、口、頬、自然な肌の質感を最優先して保つ。表情変更で目を大きく丸くしたり、頬を幼くしたり、顎を縮めたりしない。
- 温かいブラウンの髪、自然な前髪、ゆるいアップスタイル。必要に応じて服装変更は可。ただし顔の同一性が最優先。
- 大人の落ち着き、親しみやすさ、自然な笑顔、穏やかな距離感。過度な若返り・アニメ風の誇張を避ける。
- LPの基本衣装はアイボリー系のニット。世界観は暖色の室内照明、柔らかいリビング、猫のいる日常。

## 表情マスター候補
通常／微笑み／笑顔／照れ／真剣／困り顔／照れ笑い／嬉しい／驚き／考え中／少し悲しい／甘える。**表情だけ**を動かし、同一人物の顔立ちと38歳の自然な印象を維持する。

## 制作・検収
1. 生成の際はLPの元画像を最優先の視覚参照にする。キャラクターシートのみを繰り返し参照して顔のズレを累積させない。
2. 正面・左右横顔・斜め・全身・表情差分をLP基準と見比べる。
3. とくに表情差分の幼さ、目の拡大、頬と顎の変化を検査する。
4. 合格した個別素材のみラウンジ・オープニング・チャットに採用する。シートは構図資料であり個別画像の切り出しは原則しない。
5. 現時点でLP元画像・最終マスターシートのバイナリはリポジトリ未格納。**画像の保存完了や画面差し替え完了とは扱わない**。
